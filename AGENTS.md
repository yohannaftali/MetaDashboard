# AGENTS.md — MetaDashboard

Profit calendar for several MT5 accounts (see `README.md` for use).

| File | What |
|---|---|
| `pyproject.toml` | uv project, `flet[desktop]==0.86.4`; scripts `metadashboard` (app) and `metadashboard-fetch` (core), gui-script `metadashboard-gui` (no console, output to `data/metadashboard.log`). |
| `src/metadashboard/shortcuts.py` | `metadashboard --install-shortcuts` / `--remove-shortcuts`: Start menu + desktop `.lnk` to `metadashboard-gui.exe` (next to the running script, else on `PATH`). Public install = uv's installer + `uv tool install <GitHub main zip>` + this; no own `irm \| iex` script (Defender flags that pattern for an unknown URL as `Trojan:Win32/Commando.A!ml`). Test with `UV_TOOL_DIR` / `UV_TOOL_BIN_DIR` / `METADASHBOARD_HOME` set to a temp folder. |
| `src/metadashboard/app.py` | Flet desktop app (`uv run metadashboard`, `--demo`, `--web`, `--db`, `--install-shortcuts`, `--remove-shortcuts`): header (account, Year / Month / Compare, period, Refresh, Settings, theme), cards, year / month calendar, Compare (grouped bar charts drawn with Containers: daily % of the month, monthly % of the year, one bar per account in `SERIES_LIGHT` / `SERIES_DARK`, the dataviz reference categorical palette validated on the app panels, plus a table), Settings dialog. Ports the page's numbers (`combined_days`, `period`, `day_pct`). Refresh runs `fetch_all` in a thread; auto refresh every `refresh_minutes` (settings table, 0 = off, min 5) without error dialogs. |
| `src/metadashboard/core.py` | Reads the accounts from the store, fetches each account's deal history with the `MetaTrader5` package (investor password), computes the daily rows (`daily_rows`), caches them in `data/` (`ROOT`: the clone, or `%LOCALAPPDATA%\MetaDashboard` when installed, `METADASHBOARD_HOME` overrides), writes `output/dashboard.html` from the template (`uv run metadashboard-fetch`). `--demo` makes random accounts. |
| `src/metadashboard/terminal.py` | `Terminal` context for `fetch_all` (Windows, ctypes): starts the monitoring terminal minimized (`/portable`), re-minimizes after each login, closes it with `WM_CLOSE` after the fetch (kill after 20 s); a terminal already running is left alone. |
| `src/metadashboard/monitor.py` | Settings > Create monitoring terminal: copies an installed MT5 (Program Files) to `ROOT/mt5` without `bases`, logs, MQL5 and the source's `config/accounts.dat` (saved logins, possibly trading passwords: never copied), plus the newest `servers.dat` (from the source's %APPDATA% data folder, via `origin.txt`). `accounts()` = `bases/<server>/trades/<login>` of the copy. Log in to accounts opens the copy (fetches paused, `App.session`), the user logs in with Save password, accounts are added when it closes. |
| `src/metadashboard/store.py` | SQLite store `data/metadashboard.db`: terminal path + accounts; investor passwords optional (empty = the terminal's saved password, `fetch_mt5` then logs in without one), DPAPI-encrypted, never shown. Per-account `start_date` ("Count from", added to older databases by `ALTER TABLE`): `core.from_start` drops the earlier days in `load_cached`, `fetch_all` and the demo; caches keep the full history. A `.env` is imported once into an empty store. |
| `tools/make_icon.py` | Draws `src/metadashboard/assets/icon.ico` / `icon.png` (calendar with green / red days); `uv run --with pillow tools/make_icon.py`. The .ico is the window icon (`page.window.icon`) and the shortcuts' icon (`shortcuts.ICON`). |
| `src/metadashboard/dashboard_template.html` | The static page: vanilla JS, no external resources; the data is injected in place of `/*__DATA__*/null`. Year / month views, account selector ("All accounts" when there are several), light / dark theme. |

Rules:
1. **Never point the terminal path (Settings / `MT5_TERMINAL_PATH`) at a terminal that runs live EAs** and never run the script against the user's trading terminal: logging in switches that terminal's account. Test with `--demo`.
2. Investor (read-only) passwords only, also the ones saved in the monitoring terminal; never commit `.env`, `output/` or `data/` (balances, account numbers, the database).
3. Daily % = trading P/L / balance at the day's first trade (`daily_rows`, tested with deposits before / after trades and withdrawal-only days); month / year / week % = P/L / balance at the start of the period's first trading day.
4. Commit / push only when the user asks; commit messages end with the `Co-Authored-By` line required by the session.
5. Check after changes: the app with `uv run metadashboard --demo --db <scratch>.db` (a screenshot via `page.take_screenshot()` with `page.enable_screenshots = True`); the page with `uv run metadashboard-fetch --demo`, then a headless screenshot, e.g. `msedge --headless=new --screenshot=out.png --window-size=1400,1150 file:///.../output/dashboard.html` (append `#year` for the year view).
